# 任务卡片 · 开发文档

> 一个「纸卡 + 网页 + 手机」三端同一份数据的任务管理器。
> 纸卡负责在手上、桌上；网页负责总览和打印；App 负责在手机上快速改状态、拍卡回写。
> 文档对应版本：**Web 2.4.0 / Android APK 2.4.0（versionCode 8）**，提交 `0c6cda2` 之后。

---

## 1. 项目是什么

### 1.1 使用方式

1. 在网页上「打印 → 空白卡」，A4 一页 8 张（1/8 A4，105 × 74.25mm），默认双面（正面卡片 + 背面复盘）。
2. 手写填卡，放在文件夹里；每张卡右上角有二维码，编码是 `http://<局域网IP>:8088/t/<6位短码>`。
3. 手机扫卡上的码 → 打开这张卡的落地页 → **拍一张，更新这张卡**（拍卡面 OCR 后写回），或手动点状态。
4. 电脑看板/全部任务/统计页实时同步（PocketBase SSE，通常 1 秒内）。
5. 完成后卡片进「已完成」，设了重复的任务会自动生成下一张。

### 1.2 设计取舍

- **短码与任务 ID 解耦**：二维码里只有 6 位短码，换库、改任务 ID、补印都不会让纸上那张卡失效。
- **纸卡即身份**：每张空白卡在库里对应一条 `draft` 占位任务 + 一条 `short_links`；拍卡先解二维码确定「这是哪张」，再让模型只读卡面文字。
- **本地优先**：全部数据存在本机 PocketBase（SQLite），不依赖云；导出/备份在设置页一键完成。
- **瑞士风视觉**：白底、黑字、品牌红 `#D6362B`、0 圆角、细分隔线；深浅两套皮肤。

## 2. 总体架构

```
┌──────────────┐   扫码/拍卡    ┌─────────────────────────────┐
│  手机浏览器   │ ────────────► │  Express (server/index.mjs)  │  8088
│  或 原生 App  │ ◄──────────── │  · 静态托管 web/dist          │
└──────────────┘   同源 API     │  · /api,/_ 反向代理 → 8090    │
                               │  · /ds-api/* 业务接口         │
┌──────────────┐               └──────────────┬──────────────┘
│  电脑浏览器   │ ────────────────────────────►│
└──────────────┘                              │ 管理员 token + 用户 token
                                              ▼
                               ┌─────────────────────────────┐
                               │ PocketBase 0.40.6            │  8090
                               │ SQLite + SSE + 用户/管理员    │
                               └──────┬───────────────┬──────┘
                                      │               │
                          ┌───────────▼──┐   ┌────────▼─────────┐
                          │ Python       │   │ DeepSeek API      │
                          │ reportlab    │   │ deepseek-flash    │
                          │ qrcode       │   │ 文字/看图结构化    │
                          │ opencv(扫码) │   └──────────────────┘
                          └──────────────┘
```

一个端口（8088）解决全部事情：网页、API、PaperBase 代理、PDF 下载都从它出。手机只要连同一个 Wi-Fi、访问 `http://<电脑IP>:8088` 就行，不需要 HTTPS。

## 3. 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| Web | React 19 + Vite 8 + TypeScript 5.9 + Tailwind 4 | 无路由库（`web/src/lib/router.tsx` 自写 pushState 路由），无组件库 |
| 实时 | PocketBase SDK 0.28 `subscribe('*')` | 断线自动重连；SSE 走 `/api/realtime` |
| 后端 | Node 24 + Express 5 + http-proxy-middleware 4 | 代理必须挂在 `express.json()` 之前 |
| 数据库 | PocketBase 0.40.6（SQLite） | 集合规则、管理员、用户鉴权都在这层 |
| PDF | Python 3 + reportlab + qrcode | `scripts/gen_cards.py`，支持 stdin/stdout 流式 |
| 扫码 | Python + OpenCV `QRCodeDetector.detectAndDecodeMulti` | `scripts/decode_qr.py`，含旋转/放大重试 |
| OCR | DeepSeek `deepseek-flash`（支持图片输入） | Key 存 `app_settings`，不落 `.env` |
| Android | Java + AppCompat/Material3 + WebView 无关 | 原生控件四屏，AGP 8.7.2 / SDK 35 / minSdk 24 |
| PWA | `web/public/sw.js` + manifest | 只缓存壳，写入仍需联网 |

## 5. 运行与构建

### 5.1 环境要求

- Node 24（自带 `fetch`、`--env-file` 能力不必用）
- pnpm 12
- Python 3.10+，并 `pip install reportlab qrcode pillow opencv-python-headless pymupdf`
- PocketBase 0.40.6：`server/pocketbase/pocketbase.exe`（`tools/fetch-pocketbase.mjs` 下载）
- Android 构建：JDK 22、Android SDK 35（`D:/Application/AI/Android/Sdk`）、Gradle 8.10.2

### 5.2 一键启动

```bat
start-demo.cmd
```

或：

```bash
node scripts/start-demo.mjs          # 起 PB(8090) + 必要时构建前端 + 起 web(8088) + 打开浏览器
node scripts/start-demo.mjs --check  # 只检查并打印地址
node scripts/start-demo.mjs --no-open
```

启动器逻辑：检查 `http://127.0.0.1:8090/api/health` → 未起则 spawn PocketBase；`tasks` 为空自动跑 seed；检查 8088 → 未起则 spawn `node server/index.mjs`；比较 `web/src`、`index.html`、`vite.config.ts`、`package.json` 的 mtime 与 `web/dist/index.html`，需要时先 `pnpm build`。

### 5.3 手动启动

```bash
node tools/run-pocketbase.mjs                # 或 pocketbase serve --http=127.0.0.1:8090 --dir=./server/pocketbase/pb_data
node seed/seed.mjs                            # 首次：建表 + 演示数据
pnpm --dir web dev                            # 开发模式（vite 5173，代理 /api → 8090、/ds-api → 8088）
# 或
pnpm --dir web build && node server/index.mjs # 生产模式（8088 单端口）
```

### 5.4 环境变量

`server/index.mjs` 用 `dotenv` 读 `.env.local` 与 `.env`：

| 变量 | 默认 | 用途 |
| --- | --- | --- |
| `PORT` | 8088 | Web/API 端口 |
| `PB_URL` | http://127.0.0.1:8090 | PocketBase 地址 |
| `PB_ADMIN_EMAIL/PASSWORD` | admin@taskcard.local / taskcard12345 | 服务端管理员操作 |

## 6. 数据模型

PocketBase 集合（`seed/seed.mjs` 可重建）：

### 6.1 `tasks`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | text(15) | 必须 15 位，如 `tsk000000000001` |
| `title` | text(200) required | 任务名；空白卡占位为「空白卡 01」 |
| `kind` | select `short`/`long` required | 短期卡 / 长期卡片 |
| `status` | select `todo`/`doing`/`done`/`paused` | 搁置 = paused |
| `due` | text(20) | `MM-DD`（也接受 `YYYY-MM-DD`） |
| `start` | text(20) | 同上 |
| `estimate_min` | number | 分钟 |
| `description`/`materials`/`notes`/`goal` | text | 卡面文字 |
| `milestones` | json | 长期卡里程碑数组 |
| `progress` | number 0-100 | 长期卡进度 |
| `draft` | bool | 空白卡占位，不在看板/列表展示 |
| `tags` | text(200) | 逗号分隔，前端 `parseTags` |
| `checklist` | json | `[{t:"步骤",d:false}]` |
| `remind_at` | text(40) | `MM-DD HH:mm` 或 `YYYY-MM-DD HH:mm` |
| `repeat` | text(20) | `daily`/`weekdays`/`weekly`/`monthly` |
| `completed_at` | text(40) | 完成时间（ISO），改回未完成时清空 |
| `client_updated_at` | text(40) | 冲突兜底（LWW） |
| `parent` | relation(tasks) | 预留：子任务 |
| `created`/`updated` | autodate | **必须显式建**，否则 `sort=-created` 会 400 |

### 6.2 `short_links`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | text(12) required | 6 位短码，字母表 `23456789abcdefghjkmnpqrstuvwxyzABCDEFGHJKLMNPQRSTUVWXYZ` |
| `task` | relation(tasks) required | 指向任务 |
| `active` | bool | `false` = 作废；注意 PocketBase bool 默认 false，创建时要显式 `true` |
| `scans` | number | 被扫次数 |
| `last_scan_at` | text(40) | 最近一次被扫时间 |

### 6.3 `progress_logs`

`task`(relation) / `note`(text, required) / `at`(text) / `delta`(number，保留)。

### 6.4 `app_settings`（服务端专用，规则全 lock）

`deepseek_api_key` / `deepseek_model` / `deepseek_vision_model` / `write_passcode`（旧口令 `salt:sha256`，默认空）。

### 6.5 `users`（PocketBase 内置）

邮箱 + 密码登录，`name` 显示名。Web 与 App 共用。

> **当前规则**：`tasks`、`short_links`、`progress_logs` 的读写规则是公开的（纸卡落地页依赖）。账号只拦 `/ds-api` 与界面。这是已知缺口，见 §13。

## 7. 服务端接口

单端口 8088。`/api/*`、`/_/*` 原样代理到 PocketBase；`/ds-api/*` 由 Express 处理。

**鉴权**：`/ds-api` 下除 `GET /ds-api/health`、`GET /ds-api/net`、`GET/POST /ds-api/passcode` 外，都需要 `Authorization: Bearer <users token>`；未登录返回 `401 {ok:false,error:"先登录再操作",need_login:true}`。管理员操作由服务端用 superuser token 完成。

### 7.1 基础

| 方法 | 路径 | 入参 | 出参 |
| --- | --- | --- | --- |
| GET | `/ds-api/health` | — | `{ok,pb,deepseek,model,vision,dist}` |
| GET | `/ds-api/net` | — | `{ok,ip,port,lan,url}`；`url` 是给二维码用的局域网地址 |
| GET | `/ds-api/passcode` | — | `{ok,enabled:false,disabled:true}`（已停用） |

### 7.2 设置与数据

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/ds-api/settings` | `{configured,key_hint,model,vision}`，不返回完整 Key |
| POST | `/ds-api/settings` | `{api_key?,model?,vision?}`，写 `app_settings`，立即生效 |
| GET | `/ds-api/export` | 三个集合全量 JSON 下载，`taskcard-export-<stamp>.json` |
| POST | `/ds-api/backup` | 触发 PocketBase 备份，默认名 `taskcard-YYYYMMDDHHmmss.zip` |
| GET | `/ds-api/backups` | `[{key,size,modified}]` |
| GET | `/ds-api/backups/:name` | 下载 zip（校验 `^[\w.-]+\.zip$`，直接读 `pb_data/backups/`） |

### 7.3 任务

| 方法 | 路径 | 入参 | 说明 |
| --- | --- | --- | --- |
| DELETE | `/ds-api/tasks/:id` | — | 级联删 short_links、progress_logs、任务；返回 `{ok,deleted:{links,logs}}`；不存在 404 |
| POST | `/ds-api/tasks/:id/done` | — | 标记完成 + 写 `completed_at`；若 `repeat` 合法则复制生成下一张（状态 todo、due 顺延、清单重置、新短码、写一条进展日志），返回 `{ok,next:{id,code,due}}` |

**重复顺延规则**（`nextDue`）：daily +1 天；weekdays 跳过周末；weekly +7 天；monthly +1 月（月末会滚动，如 01-31 → 03-02/03）。

### 7.4 卡片

| 方法 | 路径 | 入参 | 说明 |
| --- | --- | --- | --- |
| POST | `/ds-api/cards.pdf` | `{ids[], base_url?, double_sided?}` | 已选任务拼 A4 PDF；缺短码自动建；≤200 张；返回 `application/pdf` + `x-card-count` |
| POST | `/ds-api/cards.blank` | `{count 1..64, kind, base_url?, double_sided?}` | 建 N 张 `draft` 占位任务 + 短码，出空白卡 PDF；`x-card-codes` 逗号分隔 |
| POST | `/ds-api/cards.reprint` | `{codes[] \| code, fill?, double_sided?}` | 补印：校验存在且未作废；`fill` 时用新空白卡补满整页；`x-card-count`/`x-fill-count` |
| POST | `/ds-api/cards.revoke` | `{code \| codes[]}` | 批量作废（`active:false`），返回 `{revoked,codes,failed}` |
| POST | `/ds-api/cards.restore` | `{codes[]}` | 批量恢复 |

错误码约定：参数问题 400；找不到 404；Python 缺失 501；脚本失败 502（附 stderr 末 3 行）；其他 500。

### 7.5 识别

| 方法 | 路径 | 入参 | 说明 |
| --- | --- | --- | --- |
| POST | `/ds-api/structure` | `{text}` | 文字 → 任务草稿；无 Key 时走本地规则 `localParse`，返回 `fallback:true` |
| POST | `/ds-api/ocr` | `{image:"data:image/..."}` | 纯图片 → 任务草稿（新卡） |
| POST | `/ds-api/scan` | `{image, code?}` | **先扫码后识读**：给了 `code` 就跳过解二维码；解出短码 → 查 short_links（作废返回 410）→ 读卡面 → 返回 `{ok,code,card:{id,title,kind,status,draft},fields}`；无码 422 |

**扫描管线**：`decode_qr.py`（cv2 多码识别，失败试 90/180/270 度、小图放大 2x）→ `codeFromQr` 提取 `/t/<code>` 或裸码 → `short_links?filter=code="…"&expand=task` → `readCardFields`（DeepSeek 看图，`SCAN_SYSTEM` 约束只读不猜，最多重试 2 次）→ 命中则 `scans+1`、`last_scan_at`。

**PDF 管线**：`cardsPayload()` 组装任务数组 → `renderCards()` spawn `python scripts/gen_cards.py --input - --output <tmp> --base-url <url> --codes-out ""`，stdin 写 JSON（**必须 `sys.stdin.buffer.read().decode('utf-8')`，Windows 下 `sys.stdin.read()` 会按 cp936 乱码**）→ 流回并删临时文件。

## 8. Web 前端

### 8.1 路由

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/` | Board | 三列看板：待办 / 进行中 / 已完成；顶部搜索 + 今天/逾期/有清单筛选；拖拽改状态；手机长按弹列选择；已完成只显示最近 8 张 |
| `/tasks` | TaskList | 全部任务，按状态筛选 + 搜索 |
| `/tasks/:id` | Detail | 字段编辑、状态、标签、清单、提醒、重复、进展记录、删除 |
| `/t/:code` | Landing | 扫码落地页（不套 Shell）：拍卡更新、手动状态、完成复盘、作废提示 |
| `/cards` | Cards | 卡片身份档案：分组、全选勾选框、补印、作废、恢复、补印上一批 |
| `/print` | Print | 打印空白卡：卡型、张数、双面、局域网地址、CSS 卡面预览 |
| `/capture` | Capture | 文字/图片录入；多张连拍队列 |
| `/stats` | Stats | 本周收卡/新建、连续完成天数、逾期、最近完成、标签分布 |
| `/settings` | Settings | DeepSeek Key、模型、数据导出/备份、账号说明 |
| `/login` | Login | 登录 / 注册 |

路由实现：`web/src/lib/router.tsx`（`usePathname` + `pushState` + `PopStateEvent`），`App.tsx` 里正则分发；`/t/*` 与未登录时都不套 `Shell`。

### 8.2 数据层

- `web/src/lib/pb.ts`：`new PocketBase(window.location.origin)`，`autoCancellation(false)`。
- `web/src/lib/data.ts`：
  - `useTasks()`：`getFullList({sort:'created'})` + `subscribe('*')` 合并增删改；断线由 SDK 重连。
  - `useShortLink(code)`：先查 short_links（expand task），区分「短码不存在 / 卡已删除 / 已作废」；扫码时 `scans+1`、`last_scan_at`。
  - `useTask/useUpdateTask/createTask/deleteTask/logProgress/completeTask`。
  - `completeTask(id)` 走 `/ds-api/tasks/:id/done`，返回 `{next?}`。
- `web/src/lib/auth.ts`：登录态 store（`useSyncExternalStore`），**getSnapshot 必须返回稳定引用**（PocketBase 的 `authStore.record` 每次访问都重新解析，直接返回会 React #185 死循环）；`installAuthFetch()` 给同源 `/api`、`/ds-api` 请求补 `Authorization`，401 时清态回登录页。

### 8.3 主题与首帧

- `index.html` 内联脚本在首帧前读 `taskcard:theme` 与 `prefers-color-scheme`，写 `dataset.theme` + `colorScheme`，避免深浅切换闪白。
- `applyTheme()` 临时加 `html.theme-swap *{transition:none}` 240ms，切断过渡；同时更新 `meta[theme-color]`。
- Token 见 `web/src/index.css`：`--canvas/--ink/--seal/...`，浅色为 `:root` 默认，深色为 `:root[data-theme=dark]`。

### 8.4 提醒与离线

- `web/src/lib/reminders.ts`：`tickReminders(tasks)` 每 30 秒扫一次，到点 90 秒窗口内发 `Notification`，`localStorage` 按 `taskcard:reminded:<id>:<remind_at>` 去重；标题带未完成数。
- `public/sw.js`：`taskcard-v2`，导航 network-first，静态资源 cache-first，跳过 `/api`、`/_`、`/ds-api`。
- `public/manifest.webmanifest`：standalone，主题色 `#232522`，192/512/maskable 图标。

## 9. Android 原生 App

- 包名 `local.taskcard.app`，版本 2.4.0（versionCode 8），minSdk 24 / target 35。
- 全部用代码搭 UI（无 layout XML），`Ui.java` 提供 dp/颜色/card/input/needPasscode 等工具。
- `Api.java`：`HttpURLConnection` 封装；非 GET 带 `Authorization: Bearer <token>`（同时兼容旧 `x-write-token`）；401 + `need_login` 抛 `NeedLogin`；回调切主线程。
- 四屏：
  - 看板：`ChipGroup` 筛选 + `SwipeRefreshLayout` + `RecyclerView`；`ItemTouchHelper` 右滑→进行中、左滑→完成（走 `/done`）；长按菜单（打开/进行中/完成/搁置/删除）；FAB 新建。
  - 详情：标题、状态 chips、截止/用时/开始/优先级/完成标准/周投入/材料/备注/标签/提醒/重复/清单/进度条/保存/删除；状态为 done 时保存先 PATCH 再 POST `/done`。
  - 拍照：`TakePicture`（FileProvider）+ `GetContent`；图片缩到长边 1600、JPEG 85 → `POST /ds-api/scan` → 核对对话框 → 写回。
  - 设置：服务器地址、账号（登录/换账号）、测试连接、外观三选、版本、关于。
- 首启顺序：无地址 → 弹「先连上电脑」；确认地址后若无 token → 弹「登录」；两者都齐才进看板。
- 提醒：`Reminders` 用 `AlarmManager`（有精确闹钟权限用 `setExactAndAllowWhileIdle`，否则 `setAndAllowWhileIdle`），每日 09:00 摘要；`BootReceiver` 开机重排；`ReminderReceiver` 建 `taskcard-reminders` 通知。receiver 设为 `exported=false`，`adb shell am broadcast` 打不进去（只能等闹钟）。
- 权限：`INTERNET`、`POST_NOTIFICATIONS`、`SCHEDULE_EXACT_ALARM`、`RECEIVE_BOOT_COMPLETED`；`usesCleartextTraffic=true`（局域网 http）。

## 10. 纸卡与 PDF

- A4，2 列 × 4 行 = 8 张，单张 **105 × 74.25mm**，虚线裁剪线。
- 二维码 **17mm**（14mm 在 300dpi 下 OpenCV 只能解 1/4），位于右上；码下只印短码。
- 短卡字段：任务名称 / 优先级（四格）/ 完成标准（两线）/ 开始 / 截止 / 时间盒与能量 / 情境 / 材料 / 复盘 / 备注 / 状态勾选。
- 长卡字段：任务名称 / 目标 / 周期 / 周投入 / 任务状态 / 短期里程碑（3 条）。
- 背面（双面时）：REVIEW 复盘卡 + 实际用时 / 完成日期 + 三条复盘线。
- 生成：

```bash
python scripts/gen_cards.py --input cards/tasks.json --output cards/cards.pdf --base-url http://192.168.0.108:8088
python scripts/gen_cards.py --input cards/tasks.json --output cards/cards-double.pdf --double-sided --flip long
```

参数：`--input`、`--output`、`--base-url`、`--double-sided`、`--flip long|short`、`--sample`、`--codes-out`。
网页端走 `/ds-api/cards.blank` / `cards.pdf` / `cards.reprint`，不经过 CLI。

## 11. 主要流程

1. **录任务**：`/capture` 输入文字 → `/ds-api/structure`（或本地规则）→ 草稿 → 保存（自动建短码）。
2. **打印空白卡**：`/print` → `cards.blank` → 建 N 张 draft + 短码 → PDF（默认双面）。
3. **拍卡回写**：手机扫码 `/t/<code>` 或 App「拍照」→ 图片 → `/ds-api/scan` → 字段核对 → 写回（只写卡面上读到的非空字段）。
4. **完成 / 重复**：看板拖到已完成、详情点完成、落地页点完成 → `/done` → 写 `completed_at` → 若重复则生成下一张。
5. **作废 / 补印**：`/cards` 勾选 → 作废（`active:false`，扫码 410）/ 补印（短码不变，可补满整页）。
6. **提醒**：详情设 `remind_at` → Web 到点浏览器通知；App 精确闹钟本地通知 + 每日摘要。
7. **备份**：设置页导出 JSON / 立即备份（PocketBase 整库 zip）。

## 13. 已知限制与风险

1. **集合规则仍是公开的**：登录只拦界面与 `/ds-api`，知道 IP 的人仍可直接读写 PocketBase。彻底收紧需要：任务加 `owner` + 落地页写入改服务端短码凭证 + 规则改 `@request.auth.id != ''`。
2. **单机数据**：没有云同步；换电脑靠导出/备份。
3. **拍照识别对分辨率敏感**：620px 的图可能只读到标题，2 倍（约 1200px 长边）才稳定。App 已统一缩到 1600。
4. **每月重复的月末**：`01-31 + 1月` 会滚到 3 月，不是「月底」。
5. **PWA 只缓存壳**：断网能看上次看板，不能写。
6. **无自动化 UI 测试**：回归依赖脚本与手工。
7. **CDP 页签积压**：十几页签会占满 HTTP/1.1 连接（都挂 SSE），排查时先 `/json/close` 清掉。
8. **口令功能已停用**：`WRITE_PASSCODE=on` 才恢复旧逻辑；当前用账号。

## 14. 编码约定

- TypeScript：`strict`；不用 `any`（确有需要 `unknown` + 收窄）；组件函数式 + hooks；请求错误统一 `message(e)` 提取服务端 `error`。
- 样式：Tailwind 原子类 + CSS 变量 token；不引组件库；实心红按钮统一 `bg-seal text-white`（浅色下 `text-oncanvas` 会变暗）。
- Java：程序化 UI；`Api.Cb` 回调；网络一律子线程 + 主线程回调；新增对话框统一 `Theme_Material_Light_Dialog_Alert`，按钮色 `#D6362B`。
- Python：只做「文件进、文件出」，不读数据库；stdin 一律按 UTF-8 字节解码。
- 命名：短码 6 位；任务 id 15 位 `tsk` 前缀；集合名小写复数。
- 提交：一句中文说清「做了什么 + 影响面」，如 `统计页与已完成收纳：completed_at、本周收卡…；APK 2.3.0`。

## 15. 路线图

- **收紧数据权限**（owner 字段 + 落地页服务端写 + 规则）

## 16. 排障速查

| 现象 | 原因 / 处理 |
| --- | --- |
| `sort=-created` 报 400 | 集合缺 `created`/`updated` autodate 字段，PATCH 集合补上 |
| 页面一直骨架屏 | CDP/浏览器页签积压占满连接；关掉多余页签或刷新 |
| PDF 文字乱码 | `gen_cards.py` 用了 `sys.stdin.read()`；改 `sys.stdin.buffer.read().decode('utf-8')` |
| 补印报「已作废」 | `short_links.active` 为 false（PB bool 默认 false）；PATCH 回 true |
| 扫码 410 | 卡已作废；到 `/cards` 恢复 |
| App 一直空列表 | 模拟器用 `10.0.2.2`，真机用局域网 IP；确认 8088 在跑、防火墙放行 |
| App 写操作 401 | token 失效；退出重登（设置页「账号」或首启弹窗） |
| 闹钟不准点 | 缺 `SCHEDULE_EXACT_ALARM`；`adb shell appops set local.taskcard.app SCHEDULE_EXACT_ALARM allow` |
| 通知收不到 | `POST_NOTIFICATIONS` 未授权，或 channel 被系统关 |
| 构建报 `useAndroidX` | `android/gradle.properties` 加 `android.useAndroidX=true` |
| 构建报非 ASCII 路径 | 加 `android.overridePathCheck=true` |
| `join is not defined` | 备份下载缺 `import { join } from 'node:path'` |
