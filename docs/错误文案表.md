# 错误与状态文案表

> 原则：**一句说清发生了什么 + 一句说清下一步**。不出现堆栈、英文异常名、内部路径。
> 技术细节只写进日志（`server/index.mjs` 的 console、`adb logcat`），不给用户看。

## 一、HTTP 错误码 → 用户文案

| 状态 | 触发场景 | 用户看到（Web / App） | 下一步提示 |
| --- | --- | --- | --- |
| 400 | 打印时一张没选 | 先选至少一张卡。 | 在列表里勾选后再点补印 |
| 400 | 一次选了超过 200 张 | 一次最多 200 张，分批打。 | 勾选本组 → 补印，分两批 |
| 400 | 二维码地址不是 http/https | 二维码地址要以 http:// 开头。 | 检查「服务器地址」是否漏了协议 |
| 400 | 口令不是 4–12 位数字 | 口令用 4–12 位数字。 | 重新输入 |
| 400 | 创建任务缺标题 | 标题不能为空。 | 填一个能认出来的名字 |
| 401 | 未登录 / token 过期 | 请先登录后再操作。 | 回到登录页重新登录 |
| 401 | 需要写操作口令 | 这台设备还没有写权限。输入一次口令即可修改数据。 | 输入口令后自动重试 |
| 404 | 短码不存在 | 这张卡不在系统里了。可能短码印错，或数据库还没导入。 | 核对纸卡上的短码 |
| 404 | 任务已被删除 | 这张卡不在系统里了。它可能已经被删掉。 | 纸卡留作便签，或补印新卡 |
| 410 | 短码已作废 | 这张卡已经作废（短码 X）。 | 用「卡片」页补印一张新卡 |
| 422 | 照片里没有二维码 | 照片里没找到二维码。把整张卡拍全，右上角要清楚。 | 重拍，或改用「从相册选」 |
| 501 | 本机没装 Python / reportlab | 这台电脑还不能生成 PDF。先安装 Python 和 reportlab、qrcode。 | 按 README「打印纸卡」安装依赖 |
| 501 | 没配看图模型 | 还没配置看图模型。去「设置 → 模型与 Key」填一个能读图的模型。 | 填 `deepseek-flash` |
| 502 | 生成 PDF 的脚本报错 | 排版没有成功。请重试一次；还不行就看电脑端的日志。 | 重试 / 看终端输出 |
| 500 | 其他未预期错误 | 服务出了点问题，稍后再试。 | 重试；反复出现就重启服务 |

## 二、网络与连接

| 现象 | 用户看到 | 下一步 |
| --- | --- | --- |
| 电脑服务没开 | 连不上服务器。请检查电脑端服务与 Wi-Fi。 | 双击 `start-demo.cmd` |
| 手机与电脑不同 Wi-Fi | 连不上服务器。请检查电脑端服务与 Wi-Fi。 | 连同一个 Wi-Fi，或开热点 |
| 手机用了 `127.0.0.1` | 手机扫不开本机地址。 | 把地址改成电脑的局域网 IP |
| 实时通道断开 | 实时更新已断开，正在重连… | 无需操作，会自动恢复 |

## 三、模型与识别

| 场景 | 用户看到 | 下一步 |
| --- | --- | --- |
| 没配 Key，走本地规则 | 没有配置模型，已按本地规则解析。结果可以继续改。 | 想要更准就去设置里填 Key |
| 模型返回不是 JSON | 这次没读出卡面内容（可能字太潦草或照片太暗），再拍一张试试。 | 字写清楚、光线均匀 |
| 识别不到二维码 | 照片里没找到二维码… | 拍全整张卡 |
| 识别到卡但字段为空 | 卡面上没读到内容，可以把字写清楚一点再拍。 | 重拍，或手动填 |

## 六、写法约定（给以后加功能的人）

1. **不用感叹号**，不用「哦」「啦」这类语气词；不用「抱歉」开头。
2. **错误三件套**：发生了什么（短句）→ 为什么（可选，一句）→ 怎么办（动词开头）。
3. **数字与短码原样保留**（`短码 a7K2m9`、`下一张 11-09`），方便对照纸卡。
4. 技术名词只在必要处出现（PocketBase、Python），且后面紧跟「怎么办」。
5. 同一个动作在 Web 与 App 用同一句话，只允许因控件不同而微调（如 toast 去掉句号以外的差异）。
6. 任何新错误先在这张表里加一行，再写代码。
